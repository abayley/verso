Prototype: five watercolour texture treatments for the Moebius editor theme, switchable from the floating bar. Baseline is the theme's current banked speckle; the variants add wash mottling, chromatic granulation with selective flecks, a cool-to-warm hue fade with a grain-dithered transition, hatched shadow banks, and all of them combined quietly.

PROTOTYPE. Question: can non-uniform colour read as watercolour on the Moebius surfaces, within ADR-081's texture rules (self-contained SVG data-URI background layers only)? Flip variants with the bar below or the arrow keys; switch day and night with the sun and moon buttons. Reference: the hat, bench and wall in docs/mockups/images/moebius-girl-on-bench.jpg. Every texture here is a background layer built as a data URI at runtime; the winning recipe would be baked static in the real theme, exactly as the current speckle is.
