Mockup P: a line-art treatment, laid out as the editor now is. Pure white, a single 1.5 pixel ink weight for every border, icon, and divider, no colour and no fills; selection and active states are diagonal hatching, the page tree is a full-height rail whose nested pages hang from drawn connector lines, and the command bar is one outlined pill. The type is Avenir Next, falling back to Segoe UI and then Helvetica: an even geometric sans with no contrast in the stroke, so the letterforms carry the same weight as the drawn line; the title is set at 300 to match the hairline.
